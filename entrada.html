Factorización

La factorización es el proceso de descomponer una expresión algebraica en factores más simples.

Tipo Descripción Ejemplo
Factor común Se extrae el mayor divisor común. 6x² + 9x = 3x(2x + 3)
Diferencia de cuadrados a² - b² = (a + b)(a - b) x² - 16 = (x + 4)(x - 4)
Trinomio cuadrado perfecto Se reconoce la forma (a ± b)². x² + 6x + 9 = (x + 3)²
Suma y diferencia de cubos a³ + b³ = (a+b)(a²-ab+b²)
a³-b³=(a-b)(a²+ab+b²) 		x³ - 8 = (x - 2)(x² + 2x + 4)
